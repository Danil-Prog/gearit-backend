## Gearit-backend

### Инструкция запуску

1. Собираем docker образ backend-a (из директории backend/)
```shell
./gradlew jibDockerBuild
```

2. Переходим в docker/ директорию.
3. Поднимаем БД + backend.

```shell
docker compose up -d
```

### Обновление. 

1. Подтягиваем изменения из репозитория. 

```shell
git pull
```

2. Повторяем действия с 1 по 3 (Инструкция по запуску).

Таким образом перезапустится только обновленный образ. 

Каждый вызов команды jibDockerBuild - перезаписывает образ backend-a.


### Полезное

1. Если контейнер `ghcr.io/danil-prog/gearit-backend:latest` 
падает с ошибкой одна из распространенных причин - конфликт БД из-за миграции, 
для устранения необходимо очистить полностью БД, 
это можно сделать полностью удалив все таблицы из какого-либо менеджера (Idea, PGAdmin и пр.) 
или перезапустить контейнер командой:

```shell
docker compose down gearit-data
```

2. Просмотреть нагрузку на контейнеры:

```shell
docker compose stats
```

UPD: если выполнить команду выше из директории docker/ - то результат статистики будет только по приложению gearit.

3. Удалить все неиспользуемые в данный момент образы 

```shell
docker rmi -f $(docker images -aq)
```

4. Полностью удалить все данные о контейнерах(volumes, networks и пр.)

```shell
docker system prune
```
